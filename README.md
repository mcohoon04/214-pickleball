# 214 Pickleball

Private court scheduling app for Kris's pickleball group. Built for iOS.

## Overview
- iOS native app (Swift/SwiftUI)
- Shared calendar for booking court time
- User accounts with authentication
- Push notifications + email notifications
- Backend: TBD (Supabase or custom)
